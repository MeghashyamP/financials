# Financials - Personal Financial Dashboard

A privacy-focused, zero-backend personal finance dashboard built with React, Vite, and IndexedDB.

## Features
- **Dashboard**: Executive summary, income vs expense breakdowns, and monthly trends.
- **Transactions**: Full CRUD table, advanced multi-filter search, category assignment, and bulk edit actions.
- **Net Worth Tracking**: Asset allocation, liability management, and historical net worth trends.
- **Budgeting & Goals**: Category progress tracking, rollover budgets, and targeted savings goals.
- **Statement Importers**: Intelligent PDF statement parsing, client-side OCR for scanned documents, and CSV mapping.
- **Local Data Privacy**: 100% client-side data storage powered by IndexedDB (`FinancialsDB`).

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
